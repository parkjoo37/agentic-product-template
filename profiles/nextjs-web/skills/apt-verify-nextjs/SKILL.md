# Next.js 전체 검증

메인만 실행한다. 병렬 작업 중인 구현·검증 에이전트는 대응 테스트만 돌린다.

패키지 스크립트가 있을 때만 이 순서로 실행한다.

1. `npm run lint`
2. `npm run typecheck`
3. `npm test`
4. 화면, 라우트, 폼, 클라이언트 상태를 바꿨으면 `npm run test:e2e`

각 명령의 종료 코드를 보고한다. 스크립트가 없으면 그 항목을 건너뛴 이유와 함께 미검증으로 적는다. 없는 검사를 통과로 적지 않는다.
