# 고정 과제

하네스 규칙이나 모델 배치를 바꾸면, 여기 과제만 다시 실행하고 이전 실행 기록과 비교한다.

과제는 5개에서 10개로 유지한다. 실제로 실패했거나 위험도가 높았던 작업만 올린다. 통과시키기 쉬운 과제를 새로 만들지 않는다.

각 과제는 `docs/harness/fixtures/<slug>.md`에 둔다.

- 기준 커밋: 그 작업을 시작하기 직전의 커밋 해시
- 위험도
- 수용 조건
- 수정 허용 경로
- 검증 명령
- 이전 결과: 첫 통과 여부, 재시도, 승격 횟수

과제는 기준 커밋에서 만든 별도 브랜치나 워크트리에서만 실행하고, PR을 열거나 병합하지 않는다.
