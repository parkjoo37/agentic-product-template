# 하네스 기록

이 디렉터리는 서비스 기능 문서가 아니라, AI로 개발한 과정의 기록이다.

- `model-routing.md`: 역할별 모델. 템플릿 기본값은 Composer 2.5, Grok 4.7, L3 검증만 Claude Sonnet 5.5다. 서비스가 고치면 템플릿 갱신이 덮어쓰지 않는다
- `requirements/`: 자연어 요청에서 만든 요구사항과 수용 조건
- `decisions/`: 위험 결정과 그 답
- `tasks/`: 위험도와 파일 경계가 나뉜 작업
- `runs/`: 요청 하나의 시간, 위험도, 개입, 재시도, 승격, 검증 기록
- `fixtures/`: 규칙이나 모델을 바꾼 뒤 다시 돌려 비교하는 고정 과제
- `run.example.json`: 실행 기록 형식

서비스 기획 문서를 여기에 섞지 않는다.
