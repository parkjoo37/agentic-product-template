# 하네스 채점

1. `docs/harness/fixtures/`의 실제 과제만 고른다. `EXAMPLE.md`는 실행하지 않는다.
2. 과제마다 적힌 기준 커밋에서 새 브랜치나 워크트리를 만든다. 기본 브랜치에서 실행하지 않는다.
3. 현재 라우팅으로 한 번 구현하고 검증한다. PR을 열지 않고, 끝나면 그 브랜치를 지운다.
4. 결과를 `docs/harness/runs/`에 남긴다. 위험도, 첫 검증 결과, 재시도, 승격 횟수를 포함한다.
5. 이전 실행과 비교해 첫 통과율과 평균 승격 횟수가 어떻게 달라졌는지 `lessons/`에 적는다.
6. 과제가 5개 미만이면 채점 대신, 부족한 개수와 후보 작업을 보고한다.
